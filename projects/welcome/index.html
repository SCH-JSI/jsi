Project 001 · How it works

Say it.
Ship it.

JSI is designed for low ceremony. Make an HTML project with Claude, tell it to publish, preview the result, and approve it. The rest is handled for you.

01

Make

Describe the tool, game, page, or experiment you want Claude to create.

02

Preview

Claude adds it to a safe draft branch and gives you a link to check.

03

Approve

Say “publish it.” Claude merges the draft and GitHub puts it online.

“Publish this to JSI as a project called Weekend Weather.”
